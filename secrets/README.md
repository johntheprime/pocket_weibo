# secrets/ — local signing material (gitignored except *.example and this README)

Everything under this directory except `*.example` files and this README is **never committed**:
keystores, passwords, and base64 keystore blobs carry the release signature.

## Layout (local, gitignored)

| File | Purpose |
|------|---------|
| `github-keystore-secrets.local.txt` | Same names/values as GitHub Actions secrets (`KEYSTORE_PASSWORD`, optional `KEY_PASSWORD`, `KEY_ALIAS`, optional `ANDROID_KEYSTORE_BASE64*`). Feed for `scripts/build-pocketweibo-release.sh`. |
| `github-keystore-secrets.local.ANDROID_KEYSTORE_BASE64` | Companion file: raw base64 of the release keystore (output of `base64 -w0 your.keystore` on Linux). |
| `ANDROID_KEYSTORE_BASE64.local.txt` | Older copy of the keystore base64 (kept for local convenience). |
| `ci-release.keystore` | Decoded release keystore — regenerated by `scripts/build-pocketweibo-release.sh` (and by CI) on each run. |
| `keystore.properties` | Written by the build script; consumed by `app/build.gradle.kts` release signing (`storeFile` is resolved **relative to this file**, so `storeFile=ci-release.keystore` means `secrets/ci-release.keystore`). |
| `release.keystore` / `pocket-weibo-github-release.keystore` | Source keystores (local machines only). |

## Templates (tracked)

- `github-keystore-secrets.local.txt.example` — copy to `github-keystore-secrets.local.txt` and fill in.
- `keystore.properties.example` — optional manual Gradle signing setup.

See **`docs/FIX.md`** ("CI release signing") for the full flow, and `.github/workflows/build-apk.yml`
which regenerates `secrets/ci-release.keystore` + `secrets/keystore.properties` from GitHub Actions
secrets at build time.
